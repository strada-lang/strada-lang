# Benchmark sweep — 2026-11-26

Five multi-language benchmarks across six languages. Wall-clock seconds,
**best of 3 runs**, lower is better. Run via
`./run_benchmarks.sh -r 3 --langs strada,perl,python,ruby,php,node <bench>`,
one benchmark at a time, each started with the load average below 0.7.

- Box: 2-core AWS dev host (shared: other work started during the long runs).
- Toolchains: Strada (commit `fcca36e`) / Perl 5.38.2 / Python 3.12.3 /
  Ruby 3.2.3 / Node v24.15.0 / PHP 8.3.6. The other languages are the same
  versions as in `RESULTS_2026-11-18.md`.

## How the figures were chosen

- **Strada**: this sweep. Functions was timed separately at higher precision
  (best of 40): 2.3 ms; the runner prints 0.002s. Speedups use 0.0023.
- **Other languages**: the faster of this sweep and the 2026-11-18 sweep, per
  cell. The host was not quiet during the multi-minute runs (Perl compute took
  112 s and 150 s in two attempts against 96.6 s on the 18th, with nothing
  changed), so taking today's slower times would overstate Strada's lead.
  Cells taken from 11-18: Perl/Python/Ruby compute, Python/Ruby strings,
  Python array/hash, Python/Ruby OOP, Node functions, PHP compute/functions.
