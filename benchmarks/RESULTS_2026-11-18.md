# Benchmark sweep — 2026-11-18

Five full multi-language benchmarks across all six languages. Wall-clock
seconds, **best of 3 runs**, lower is better. Run via
`RUNS=3 ./run_benchmarks.sh -r 3 --langs strada,perl,python,ruby,php,node <bench>`,
one benchmark at a time on a quiet host (load < 0.7 before each).

- Box: 2-core AWS dev host.
- Toolchains: Strada (this tree, commit after `7041d08`) / Perl 5.38.2 / Python 3.12.3 /
  Ruby 3.2.3 / Node v24.15.0 / PHP 8.3.6.

## Notes

- Strada wins every benchmark against every language.
- Compared with the 2026-06-19 sweep (`RESULTS_2026-06-19.md`), Strada is faster on
  compute (0.912s -> 0.474s) and functions (0.014s -> 0.003s), and slower on OOP
  (0.023s -> 0.036s), strings (0.055s -> 0.064s) and array/hash (0.101s -> 0.126s).
  The slowdowns come from this cycle's Perl-semantics work (integer overflow
  promotion, pooled objects releasing their values, hash index shrinking); the
  regressions that were not semantics-driven were fixed in `c605842`.
- Functions at 0.003s is near the timer's resolution, so its speedup figures are
  approximate.
- Strings vs Python/Ruby is the known `+=`-on-immutable-strings pathology, not a
  general result.
